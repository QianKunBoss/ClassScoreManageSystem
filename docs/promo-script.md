## 二、核心亮点与特色（片中用到的卖点）

1. **多级管理架构** —— 总系统 → 学校 → 年级 → 班级，四级星链管理，权限清晰、责任明确，上级统御下级、层层把控。
2. **实时积分追踪** —— 积分实时更新，排行榜自动排序；每一次加减分都留痕，全程可追溯。
3. **可视化座位表** —— 拖拽式座位编排，支持分组与行列自定义，班级分布一目了然。
4. **快捷模板** —— 预设常用积分模板一键应用，也支持自定义，赋能日常高频操作。
5. **数据统计** —— 多维度数据扫描与趋势图表，帮助管理者掌握班级整体态势。
6. **安全可靠** —— 基于 Session 的认证体系，密码 BCrypt 加密存储，关键操作需二次确认，防误触。

## 四、视觉与听觉建议

- **画面风格**：延续官网「宇宙科技风」——深空蓝黑底 `#070b14`、钢蓝主色 `#4a7ab5`、银灰文字 `#c2cfe0`；纯色发光，不用花哨渐变。镜头多用缓慢推拉与视差，克制不炫技。
- **字幕**：关键旁白以钢蓝描边字幕居中显示，与画面留白呼应。
- **配乐**：开头低频氛围 pad，痛点段切入轻微紧张感节奏，产品亮相后以稳定、向上的旋律推进，结尾收束为开阔长音。
- **节奏**：每个亮点 12–16 秒，信息单一、不堆砌；段与段之间留 0.5–1 秒黑场/星海过渡，保证「有力」而非「拥挤」。
